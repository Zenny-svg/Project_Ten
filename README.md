**What does this project do?**

It's a simple demonstration of a website. It will greet the user by name as long as its written into the URL. It also lists my goals for this class as well as a fact about me.

**What is the project built with?**

I used Python, HTML, a stylesheet, and most recently git in order to demonstate my skills.

**How to run it:**

In app.py, you can run the terminal or type "python app.py". It will provide you with a IP to CTRL + click on, which will show you to the testing website.
